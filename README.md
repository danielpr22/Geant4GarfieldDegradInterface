======================================
=== Geant4GarfieldDegradInterface ====
======================================
 
This project uses an interface between Geant4, Garfield++ and Degrad for the simulation of the Dual Multiwire 
Proportional X-ray counter (DMPX) to be installed on the 'Tokamak à Configuration Variable' (TCV), housed
at the Swiss Plasma Center (EPFL).

The interface was designed by Pfeiffer et al. in the paper 'Interacing Geant4, Garfield++ and Degrad for 
the simulation of gaseous detectors'. My contribution to this project is the updating of the ALICE and 
Xenon examples in the original interface project, and the addition of the DMPX detector geometry

 
 Documentation
 -------------
 Please check https://geant4garfielddegradinterface.readthedocs.io for a complete description of how to
 implement the interface project with your own geometry.
